# 1.3.0

**New**
- EarthMC map now works in the **Nether** ("Overworld Coords" mode)
- World-map **zoom-out overview** with crisp tiled town outlines
- Faster, **live player positions** from squaremap (map, minimap and the nearby list)
- Nation panel: **active-based chunk bonus** with a "drops in…" projection and an inactive-resident count
- **One town popup** shared by search and right-click, with a **Route** button
- **Hover a town** to see its mayor and nation instantly
- **Dark Buttons** setting — flat dark UI buttons
- **Darken Map** setting — dim the squaremap on the world map and minimap
- Search bar stays put while panning and only clears when you click away

Plus assorted fixes and performance improvements.

Available for Minecraft **1.21.11**.
