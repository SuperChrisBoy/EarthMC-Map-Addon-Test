# 1.3.1

**Fixes**
- **Full world-map zoom-out works again.** A recent **Xaero's World Map** update (1.42.0) moved its zoom limit into a new internal method, which silently disabled the "World Map Overview" zoom-out. The mod now hooks both the new and older Xaero versions, so zooming all the way out to the whole EarthMC map works regardless of which Xaero you're on.
- Rebuilt against the latest Xaero's Minimap / World Map.

Bug-fix release — no feature changes.

Available for Minecraft **1.21.11**, **26.1.x**, and **26.2**.
